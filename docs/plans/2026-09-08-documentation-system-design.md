# AudioSpider 中文文档体系设计

## 目标

让第一次接触 Python、Conda、SQLite 和爬虫的用户，也能按照根目录 README 完成环境安装、受控探测、采集、下载、检查和故障恢复；让维护者可以进一步进入专题指南、接口参考和设计文档，而不必从源码反推行为。

## 方案选择

采用四层渐进式文档，而不是把所有信息继续堆进一个超长 README：

1. 根 README：解释项目是什么、最安全的首次运行路径以及常用命令。
2. `docs/getting-started/`：面向新手的逐步安装和首跑教程。
3. `docs/guides/`：面向操作者的发现、采集、下载、运维和排障指南。
4. `docs/reference/` 与 `docs/design/`：面向开发者的 CLI、配置、数据库、适配器、架构、安全和数据流说明。

代码层增加两个正式入口：`doctor.py` 负责环境、目录、依赖、ffmpeg、数据库和磁盘检查；`probe.py` 负责以小规模参数真实访问单个来源，并使用临时数据库避免污染正式任务库。Shell 脚本只做薄包装，全部转发到现有 Python 入口。

## 边界

- 不改变现有 `discover.py`、`collect.py`、`main.py` 的核心使用方式。
- 不默认启动大规模爬取或下载。
- 文档明确区分“发现 feed”“收集媒体 URL”“下载文件”三个动作。
- 真实站点探测必须有严格请求上限并输出结构化结果。
- 文档中不承诺 B站、小宇宙、喜马拉雅等外部接口永久可用。
